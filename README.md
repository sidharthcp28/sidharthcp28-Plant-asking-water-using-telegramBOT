# **Plant Asking Water Using Telegram BOT**

A small project using the NodeMCU ESP8266 board and the YL-69/YL-39 soil moisture sensor to create a smart device for plant watering management with Telegram BOT integration.

---

## **Project Overview**

This project, **"Plant Asking Water Using Telegram BOT"**, is a smart device designed to monitor and manage a plant's watering needs using real-time soil moisture levels. The device communicates with a Telegram bot, enabling users to control and monitor the watering process remotely.  

### **Key Features**
- 🌱 **Real-Time Soil Monitoring**: The device updates the soil moisture level in real time.  
- 📲 **Telegram Alerts**: Sends alerts when the soil becomes too dry or too wet.  
- ⚙️ **Customizable Settings**: Users can:
  - Set desired soil moisture levels.  
  - Adjust watering frequency.  
  - Monitor the plant's overall health.  

### **Why This Project?**
In today’s fast-paced, technology-driven age, many people take up gardening as a hobby to relieve stress and refresh their minds. However, maintaining plants, especially watering them, often becomes a challenge. This project automates the process, ensuring plants get the care they need without constant human intervention.

---

## **Components Used**
1. **NodeMCU ESP8266**  
   - A Wi-Fi-enabled microcontroller for IoT applications.  
2. **Soil Moisture Sensor (YL-69/YL-39)**  
   - Measures soil moisture levels to determine whether the plant needs water.  
3. **9V Battery**  
   - Powers the NodeMCU board.  
4. **Telegram BOT**  
   - Acts as the interface for controlling and monitoring the device.  
5. **Arduino IDE**  
   - Used to program the NodeMCU with an easy-to-use interface.

---

## **How It Works**
1. **Hardware**:  
   - The soil moisture sensor continuously measures the soil's moisture level.  
   - The NodeMCU processes this data and communicates with the Telegram bot via Wi-Fi.  

2. **Telegram BOT**:  
   - Sends real-time updates on soil moisture levels.  
   - Alerts users when the soil becomes too dry or too wet.  
   - Allows users to set thresholds for soil moisture and customize watering schedules.  

3. **Automation**:  
   - Based on the moisture levels, the system determines whether the plant needs watering and sends alerts or executes commands accordingly.
